# 自己搭配博客歌单

目前 `dist/assets/music-config.js` 的 `playerId` 为 `demo`，这是明月浩空官方公用播放器。网页上的「歌单」按钮只负责选择现有歌单，不能替你修改官方公用歌单。

## 最快的切换方法

1. 登录 [明月浩空管理后台](https://myhkw.cn/admin/user/login)。
2. 新建自己的播放器，并在播放器里建歌单、加歌曲；网站域名填 `lanceashire.github.io`。
3. 从后台复制播放器调用代码，找到其中 `key="..."` 或 `/api/player/...` 的 ID。
4. 在 GitHub 打开 `dist/assets/music-config.js`，把 `demo` 换成这个 ID 并提交。
5. 等 GitHub Pages 自动部署完成，刷新博客。以后改歌曲只需在明月浩空后台修改同一个播放器。

> 这里需要填的是**明月浩空播放器 ID**，不是网易云歌单 ID、歌单链接、账号或密码。

## 1. 创建自己的播放器与歌单

1. 打开 [明月浩空](https://myhkw.cn/)，注册并登录管理后台。
2. 在自己的账号里创建或打开播放器，建立自己的歌单。
3. 添加歌曲：可以通过平台搜索添加，或按后台提供的来源类型填写歌曲／歌单链接、ID。网易云歌单链接一般形如 `https://music.163.com/#/playlist?id=123456789`，其中数字是网易云歌单 ID。
4. 将歌单关联到自己的播放器，调整顺序并保存。可以按喜欢的用途分为「恶魔城／游戏原声」「古典／管风琴」「日常循环」等多个歌单。
5. 如果后台要求绑定网站域名，填写 `lanceashire.github.io`；域名栏不要填 `/jiezichuan-s-blog/` 路径。
6. 在后台获取播放器调用代码，找到 `key="..."` 或 `/api/player/...` 中的播放器 ID。

官方支持多平台搜索、歌单调用和自定义歌曲。账号版本可能影响批量导入、同步等功能，以后台实际开放选项为准；这里没有登录你的账号，未代你创建或保存歌单。

## 2. 让博客使用你的播放器

只改一个文件：`dist/assets/music-config.js`。

```js
window.BLOG_MUSIC_CONFIG = {
  playerId: '这里填你自己的播放器ID'
};
```

这里填写的是**明月浩空播放器 ID**，不是网易云歌单 ID、登录密码或 API 密钥。播放器 ID 本来就会出现在公开网页的调用代码中。

在 GitHub 网页打开该文件 → 点铅笔编辑 → 修改 `demo` → 提交到 `main`。等 Actions 中的 Pages 部署完成，刷新博客。以后在明月浩空后台改这个播放器的歌单，通常无需重新改博客代码。

换 ID 后如短时间仍显示旧配置，可强制刷新页面，或把各页面 `music-config.js` 后的 `v=` 版本号改成新值。不要删除 `music.js`、`music.css`，它们负责博客外观与交互。

## 3. 页面上的操作

- 播放／暂停，上一首／下一首：中间一排按钮。
- 两端双箭头：切换上一个／下一个歌单。
- 随机播放／专辑循环／单曲循环：点击「播放模式」按钮切换。
- 歌单：展开列表，选择歌单后再选择歌曲；点击列表标题返回。
- 进度：整条区域均可点击或拖动；键盘左右键每次调整 5 秒。
- 音量：直接拖动底部滑块；扬声器按钮静音／恢复。部分手机的网页音量由系统接管。
- 歌词：有歌词时控制歌词开关；没有歌词的曲目不会凭空显示歌词。

播放器仍依赖第三方服务和平台音源。单曲不可用时先在同一歌单换一首；如果整个组件未加载，检查网络、播放器 ID 和域名授权。该服务可能限制同一浏览器多个页面同时加载播放器，先关闭其他博客音乐页再重试。
